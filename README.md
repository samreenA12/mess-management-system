# 🍽️ Mess Management System

A desktop-based Mess Management System developed using **.NET Framework and C#**,
with a **MySQL** database backend.

## 📌 Features
- Student registration and management
- Daily meal tracking (breakfast, lunch, dinner)
- Monthly billing and fee calculation
- Admin dashboard to manage records
- Database connectivity using MySQL

## 🛠️ Tech Stack
| Technology | Usage |
|------------|-------|
| C# / .NET | Frontend & Logic |
| MySQL | Database |
| MS Office | Reports |

## 🚀 How to Run
1. Clone this repository
2. Open the solution file (`.sln`) in Visual Studio
3. Set up MySQL database using the provided SQL file
4. Build and Run the project
